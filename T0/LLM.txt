Done. Ported the T0 compiler to Python 3 for full parity, no .NET needed.

**New file:** `t0comp.py` (~1250 lines, stdlib only, needs `kern.t0` next to it)

**Use:**
```
python t0comp.py [ options... ] file...
   -o file    output base (default: 't0out')
   -r name    run-function base (default: same as output)
   -m a,b     entry point(s)
   -nf        disable flow analysis
```
Same CLI semantics as `T0Comp.cs`: `--`, `-o=`, comma `-m`, `[file]` echo, `ds/rs` stats, `.c` output.

**Ported faithfully:**
- Tokenizer (`NextChar`/`Unread`, `\r\n`¡÷`\n`, `"` strings, `` ` `` chars, `CX`/`add-cc` C blocks, `( -- )` effects)
- `TryParseLiteral` incl. `0x`/`0b`/sign/32-bit overflow, C# `unchecked` wrap, `c_div`/`c_mod` trunc-toward-zero, unsigned ops, shifts
- `CPU`, all `Opcode*`, `WordBuilder` control-flow stack, `WordInterpreted` flow analysis + recursion check, `WordData`, `ConstData` UTF-8 blobs, 7E/one-byte codegen, `BlobWriter` line wrapping, C templates

**Verified (no .NET/GCC here to diff against C#, so behavioural):**
- `1 2 +`, `0xFFFFFFFF 1 +`¡÷`0`, `-7 2 /`¡÷`-3`, `-7 2 %`¡÷`-1`, `-1 2 u/`¡÷`2147483647`, shifts, `u<`/`u>=`, `and/or/xor/not`
- Compile-time `.`, `.s`, `puts`, `putc`, `eqstr`, `char`/backtick/hex/bin literals, `\n\x\u` escapes, `\` comments, CRLF
- Codegen: `if/then/else`, `begin/until`, `case/of/endcase`, `{ locals }`, `data:`/`hexb|`, `preamble`, `cc:`/`add-cc:`, `CX`¡÷`T0_INTn`, multi `-m`, `-r`, `-nf` on/off, `--`
- Error paths: unknown word, overflow, stack-effect mismatch, recursion, `exitvm`

Example: `python t0comp.py -o t0out hello.t0` with `: main 1 2 + . cr ;` ¡÷ `main: ds=2 rs=1`, 9-byte code block.
