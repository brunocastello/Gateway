# ---------------------------------------------------------------- Tunnel
#
# Module 4: a generic TLS tunnel. A local application connects in plaintext
# and Gateway carries the far leg, optionally through a forward proxy,
# optionally in TLS:
#
#   local_app --plain--> :tunnel_local_port --TLS--> [proxy] --> remote:port
#
# For SSH: point the client at tunnel_local_port; the far side unwraps TLS
# (stunnel and friends) and hands the SSH stream to sshd. No local auth of
# its own, so keep tunnel_local_port behind the machine's own boundary.
